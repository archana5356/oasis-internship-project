# 🌤 WeatherSphere – Professional Weather Dashboard

## 📌 Project Overview

WeatherSphere is a Python-based weather application that provides real-time weather information using the OpenWeatherMap API. The application features a modern graphical user interface built with Tkinter and displays detailed weather information for any city.

---

## 🚀 Features

### Beginner Features
- Search weather by city name
- Real-time weather updates
- Temperature in Celsius and Fahrenheit
- Humidity
- Wind Speed
- Weather Description
- Input validation
- Error handling
- Search history

### Advanced Features
- Modern Tkinter GUI
- Weather icons
- Auto location detection
- Hourly forecast
- 5-Day forecast
- Temperature unit toggle
- Search history
- Professional dashboard

---

## ⚙ Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/WeatherSphere.git
```

### Open project

```bash
cd WeatherSphere
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Add your API Key

Open **config.py**

```python
API_KEY = "YOUR_API_KEY"
```

---

## ▶ Run the Project

```bash
python main.py
```
